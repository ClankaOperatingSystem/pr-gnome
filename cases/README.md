# Where the cases came from

Most of the cases in these directories were written in the Bugflow
project, from its own pull requests, before this repository was made.
They name that project's files and its records:

- `index.org`, `todo.org` and `cleanup.org` are its plan files. An id
  such as `C1.15` or `L6.9` is an item in one of them.
- `ADR-009` and the like are its decision records.
- `M1` and `M2` are its milestones.
- "The reviewbot" is the server, "the owner" is that project's
  maintainer, and `doctrine:pass` is the label the server once set,
  which is `review:pass` now.

None of these exist here. A case is evidence of how a judge
should answer a piece of text, so the names do not matter to the
judge, and the measurements in each policy's calibration notes were
taken on these cases as they are. A new case uses neutral names.

README.md at the top of the repository says how a case is written and
how one is added.
