# The doctrine

Standards for written work: commit messages, pull request
descriptions, comments and documents. They apply to every contributor,
human and agent.

The files in this directory are joined in filename order into one
document. A model judging a policy is given that document, then the
policy's instructions. It is not given the instructions a reviewed
repository writes for its own contributors.

Each clause has an id, such as VOICE-6 or GIT-4, and a finding cites the
id of the clause it was raised under. An id is never reused, so the
numbers have a gap where a clause was retired.

A policy's header lists the clauses it judges. A clause no policy lists
is guidance, and no finding is raised under it.

A server reviews a repository only against the policies its binding
declares for it; a skill applies them all.
